# DogLens
ios app dengan swiftui yang dapat mengolah image dari photo dan file album dengan core ml, nama appnya dog breed detection app (nanti buatkan nama app). flownya user buka app lalu ada tombol scan, tombol scan akan membuka kamera didalam app dan user bisa foto, adapun tombol upload file dimana user bisa upload file photo dari album. setelah drop file atau foto, image akan diproses coreml dan akan dideteksi (object detection) ada berapa anjing, dimana saja, breednya apa saja. image hasil inference ditampilkan ke user lalu user bisa save ke album. lalu ada swift data yang menyimpan 50 class breed anjing, saat app berhasil mendapatkan breed anjing, image akan disimpan di swift data di tab breed tersebut( ada breed galery di appnya), lalu juga ada count anjingnya ada berapa di tiap breed galery
